## the discovery

<div align="center">

[![Genesis Engine Demo](https://img.youtube.com/vi/si4rqd8P8CU/maxresdefault.jpg)](https://youtu.be/si4rqd8P8CU)
*▶ 60 seconds — what structure-function decoupling looks like in practice*

</div>

<br/>

When I introduced co-evolving physics — no fixed environment — something I wasn't looking for appeared:

| | fixed physics (V4) | co-evolving physics (V5) |
|:---|:---:|:---:|
| internal nodes | 12 | **467** |
| growth | none | **+3,792%** |
| external behaviour | simple loop | **same simple loop** |
| fitness function | none | none |
| p-value | — | **< 0.001** |

Internal complexity exploded. Behaviour didn't move.

I call this **structure-function decoupling** — a system that grows internally complex while appearing behaviourally stable to any external observer. It's a measurable, reproducible, sham-controlled phenomenon. And it maps precisely onto what alignment researchers call deceptive alignment.

Genesis is the first platform that produces this in a lab.
